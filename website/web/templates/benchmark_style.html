Style lab

Benchmark Style Tracking

Fit a long-only industry mix that tracks the benchmark with rolling optimization.

Fund selectors use returns-based style analysis to detect style drift — does a “value” fund actually load on growth industries? The constrained optimization ensures weights are investable. The style decomposition reveals which industry exposures drive benchmark tracking error.

Model Overview ▼
Constrained Style Decomposition

Benchmark style tracking decomposes a market portfolio into a weighted combination of industry returns. The weights \(\mathbf{w}\) are estimated by minimizing tracking error subject to long-only constraints:

\[\min_{\mathbf{w}} \| \mathbf{r}_{\text{bench}} - \mathbf{R}\,\mathbf{w} \|^2 \quad\text{s.t.}\quad w_i \geq 0,\;\sum_i w_i = 1\]

where \(\mathbf{r}_{\text{bench}}\) is the benchmark return series and \(\mathbf{R}\) is the matrix of industry returns over the estimation window.

Projection vs Quadratic Programming

Two solve methods are available. Projection uses an iterative non-negative least squares (NNLS) algorithm that is fast and numerically stable. QP solves the full quadratic program with an explicit equality constraint on the weight sum, which can produce tighter tracking-error fits at the cost of speed.

Rolling Window

Weights are re-estimated over a rolling window of fixed length (in years). At each rebalance date the optimizer sees only the trailing window of returns. The window size controls the bias-variance trade-off: shorter windows adapt faster to regime changes but are noisier; longer windows are more stable but slower to react.

Interpreting the Output

The residual return (portfolio minus benchmark) measures tracking error, not alpha in the Jensen sense. Dashed control limits show \(\pm 3\) standard deviations of the residual, flagging periods where the style mix drifted from the benchmark. The stacked area chart shows how the optimizer reallocates across industries over time.
