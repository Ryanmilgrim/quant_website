Risk Model

Estimate a PCA-based covariance model with GARCH conditional variance and backtest it out of sample.

LassoCV selects factor exposures, PCA rotates into principal components, and GARCH(1,1) forecasts time-varying variance.

{# ---- Model Description ---- #}
Model Overview ▼

This risk model decomposes asset returns into systematic factor exposures and idiosyncratic residuals, then estimates a time-varying covariance matrix using PCA and GARCH.

Notation

Let \(N\) denote the number of assets, \(K\) the number of Fama-French factors, \(P \leq K\) the number of retained principal components, and \(T\) the sample size (trading days).

  • \(\mathbf{r}_t = (r_{1,t}, \ldots, r_{N,t})^\top \in \mathbb{R}^N\) — excess log returns of all assets on day \(t\)
  • \(\mathbf{f}_t = (f_{1,t}, \ldots, f_{K,t})^\top \in \mathbb{R}^K\) — observed Fama-French factor returns on day \(t\)
  • \(\mathbf{F} \in \mathbb{R}^{T \times K}\) — matrix of factor returns (row \(t\) is \(\mathbf{f}_t^\top\))
  • \(\mathbf{B} \in \mathbb{R}^{N \times K}\) — factor loading (beta) matrix; entry \(\beta_{ik}\) is asset \(i\)’s exposure to factor \(k\)
  • \(\boldsymbol{\alpha} \in \mathbb{R}^N\) — vector of regression intercepts
  • \(\boldsymbol{\varepsilon}_t \in \mathbb{R}^N\) — idiosyncratic residual returns on day \(t\)
  • \(\mathbf{V} \in \mathbb{R}^{K \times P}\) — PCA eigenvector matrix mapping factors to principal components
  • \(\mathbf{z}_t = \mathbf{V}^\top \mathbf{f}_t \in \mathbb{R}^P\) — principal component scores on day \(t\)
  • \(h_{j,t}\) — conditional variance of component \(j\) (PC or residual) at time \(t\)
1. Factor Regression

Each asset’s excess return is decomposed into a systematic component driven by observable factors and an idiosyncratic residual:

\[ r_{i,t} = \alpha_i + \boldsymbol{\beta}_i^\top \mathbf{f}_t + \varepsilon_{i,t}, \qquad i = 1, \ldots, N \]

where \(\boldsymbol{\beta}_i = (\beta_{i,1}, \ldots, \beta_{i,K})^\top\) is the vector of factor loadings for asset \(i\). In matrix form for all assets simultaneously:

\[ \mathbf{r}_t = \boldsymbol{\alpha} + \mathbf{B}\,\mathbf{f}_t + \boldsymbol{\varepsilon}_t \]

Factor exposures are estimated via LassoCV for variable selection (identifying the relevant subset of factors for each asset). A Kalman filter then estimates time-varying coefficients \(\boldsymbol{\beta}_{i,t}\) and intercepts \(\alpha_{i,t}\), treating the LassoCV-selected factors as the observation matrix. The final snapshot betas are the last filtered values; the full history is available in the Time-Varying Betas chart.

2. PCA Rotation

To reduce dimensionality and orthogonalize the factor space, the factor return matrix is decomposed via singular value decomposition:

\[ \mathbf{F} = \mathbf{U}\,\mathbf{S}\,\mathbf{V}^\top \]

where \(\mathbf{U} \in \mathbb{R}^{T \times P}\) contains left singular vectors, \(\mathbf{S} \in \mathbb{R}^{P \times P}\) is diagonal with singular values, and \(\mathbf{V} \in \mathbb{R}^{K \times P}\) contains the eigenvectors. The principal component scores are:

\[ \mathbf{Z} = \mathbf{F}\,\mathbf{V} \in \mathbb{R}^{T \times P} \]

By construction, the columns of \(\mathbf{Z}\) are orthogonal. The original factors can be reconstructed as \(\mathbf{f}_t \approx \mathbf{V}\,\mathbf{z}_t\).

3. GARCH(1,1) Conditional Variance

Each principal component \(z_{j,t}\) and each asset residual \(\varepsilon_{i,t}\) is modeled with an independent GARCH(1,1) process to capture volatility clustering:

\[ h_{j,t} = \omega_j + \alpha_j\,\xi_{j,t-1}^2 + \beta_j\,h_{j,t-1} \]

where \(h_{j,t}\) is the conditional variance, \(\xi_{j,t-1}\) is the lagged innovation (PC score or residual), and \(\omega_j > 0,\; \alpha_j \geq 0,\; \beta_j \geq 0\) with \(\alpha_j + \beta_j < 1\) for stationarity. Innovations are assumed to follow a Student-\(t\) (or normal/skewed-\(t\)) distribution.

4. Factor Covariance Reconstruction

The time-varying factor covariance matrix is reconstructed from the GARCH PC variances and PCA eigenvectors:

\[ \boldsymbol{\Sigma}_{f,t} = \mathbf{V}\,\text{diag}(h_{z,1,t},\, \ldots,\, h_{z,P,t})\,\mathbf{V}^\top \in \mathbb{R}^{K \times K} \]
5. Asset Covariance Matrix

The full conditional asset covariance matrix combines systematic and idiosyncratic risk:

\[ \boldsymbol{\Sigma}_{a,t} = \mathbf{B}\,\boldsymbol{\Sigma}_{f,t}\,\mathbf{B}^\top + \mathbf{D}_{\varepsilon,t} \]

where \(\mathbf{D}_{\varepsilon,t} = \text{diag}(h_{\varepsilon,1,t},\, \ldots,\, h_{\varepsilon,N,t})\) is the diagonal matrix of GARCH-forecasted residual variances. The first term \(\mathbf{B}\,\boldsymbol{\Sigma}_{f,t}\,\mathbf{B}^\top\) captures systematic (factor-driven) risk, while \(\mathbf{D}_{\varepsilon,t}\) captures idiosyncratic risk specific to each asset.
