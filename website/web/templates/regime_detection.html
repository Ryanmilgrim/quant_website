Regime Signals

Build endogenous signals from FRED economic time series using Markov Switching models. Each regime produces soft probabilities that serve as features for downstream ML models.

Macro strategists use regime models to classify the economy into expansion, recession, or crisis states. Regime probabilities serve as conditioning variables for return forecasts and risk budgets — pipeline input for downstream ML forecasting models.

Building regime signals is an iterative process. (1) Load a FRED series, choose a stationarity transform, and inspect the result — make sure the series is well-behaved before fitting. (2) Optionally set a training cutoff to hold out out-of-sample data, then configure your Hidden Markov Model and fit. (3) Review regime probabilities and parameter significance — if a mean is not significant, try disabling Switching Trend or changing the number of regimes and refit. When satisfied, name and save to your data lake.

Model Overview ▼
Markov Switching Models

A Markov Switching model (Hamilton, 1989) assumes that an observed time series is generated by one of \(K\) unobserved regimes, each with its own parameters. The regime at time \(t\) is a latent state \(S_t \in \{0, 1, \ldots, K-1\}\) that evolves as a first-order Markov chain with transition matrix \(\mathbf{P}\):

\[P_{ij} = \Pr(S_t = j \mid S_{t-1} = i)\]
Switching Parameters

Each regime can have its own mean (switching trend) and variance (switching variance). When switching trend is enabled, the intercept \(\mu_k\) varies by regime, capturing level shifts (e.g., expansion vs recession). When switching variance is enabled, \(\sigma^2_k\) varies, capturing volatility regimes.

Autoregression (AR) Terms

For series with persistence (GDP, employment), a Markov Autoregression model (Hamilton, 1989) adds AR lags: \(y_t = \mu_{S_t} + \sum_{p=1}^{P} \phi_p\, y_{t-p} + \varepsilon_t\). The AR coefficients can optionally switch across regimes (switching AR). Without AR terms, the model may confuse autocorrelation with regime duration.

Smoothed Probabilities

After estimation via maximum likelihood (EM algorithm), the model produces smoothed probabilities \(\Pr(S_t = k \mid \mathbf{y}_{1:T})\) for each regime at every time step. These probabilities use the full sample and are the basis for the regime overlay chart. The expected duration of regime \(k\) is \(1 / (1 - P_{kk})\), derived from the diagonal of the transition matrix.

Training Cutoff

An optional training cutoff splits the sample into in-sample (for estimation) and out-of-sample (for evaluation). Out-of-sample regime probabilities are computed via the Hamilton filter using only the fitted parameters, testing whether the model generalizes beyond its training window.
